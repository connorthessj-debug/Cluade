# Verdict Format — Output Specification

> VERSION: 1.0 | This file may be improved by the self-improvement loop with user consent.

## Purpose

This is the exact output schema every scan verdict must follow. Structured, diffable, auditable. Every field is required unless marked optional.

---

## File Naming

```
scanned/YYYY-MM-DD_SYMBOL.md
```

Examples:
```
scanned/2026-05-05_AAPL.md
scanned/2026-05-05_BTCUSDT.md
scanned/2026-05-05_EURUSD.md
scanned/2026-05-05_MACRO.md
```

---

## Verdict Quality Checklist

Before saving to `scanned/`, verify:
- [ ] All sections present (no skipped headers)
- [ ] Signals table has a row for every framework dimension
- [ ] Price ladder has ≥ 8 rows with current price marked
- [ ] Trade table has all fields filled (or explicit "NO TRADE" with reason)
- [ ] Audit block has a row for every step in the protocol
- [ ] File saved to `scanned/YYYY-MM-DD_SYMBOL.md`

---

## Archive Policy

Scan files older than 30 days should be moved to `scanned/archive/`. This is done manually or as part of a future automation improvement.
